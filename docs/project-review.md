| P1 | annotate 覆盖每场标签，无修订历史 | 旧快照标签稳定，但无法恢复全部标注过程；增加标签版本和来源证据 |

模型输出通过 Schema 仅代表格式可接受。observed_action、解释文字、指标和候选分数由适配器提供，当前没有实际模型，也没有因果正确性验证。

## 真实数据核验原则

1. 从导出日志到回放核对精度，再从独立人工标注到日志核对漏检；只检查已导出的记录没有召回分母。
2. 购买、合成、库存、信使送达分开记录；无法可靠表达的语义先排除。
3. 位置、暂停时钟、未花费金币、净资产、等级内经验分别核验；缺失值不能默认为零。
4. 按比赛统计独立样本数；日志缺失不计入“没买”分母；短局/观察不足单列。
5. 同时记录覆盖与未覆盖边界。少量样本可发现错误，不能据此声明总体准确率。
