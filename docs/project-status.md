# 项目完成度与验证证据

核对日期：**2026-10-02**；代码版本：**0.3.0**。

计划更新：**2026-10-03**。已补充 L01–L12 数据准备 ToDo、学习驱动的开发流程和两份记录模板；本次为文档规划，下面的运行能力与验证基线未改变。新增任务均待执行，不代表已实现清洗、窗口、标签或预处理模块。

## 尚未完成

| 领域 | 待完成内容 | 为什么影响下一阶段 |
|---|---|---|
| 数据真实性 | 暂停时钟、位置坐标、经济含义、缺失与截断的真实对照 | 模型会学习导出错误，先保证样本语义 |
| 数据质量 | 完整性状态、丢弃原因计数、覆盖率、隔离区、持久化筛选排除清单 | 当前“导入成功/有采样”不能作为训练资格 |
| 可复现性 | 依赖锁、Git 版本、完整适配器代码、解析版本与原回放来源进入快照 | 现有哈希和主脚本副本只提供部分追踪 |
| 恢复与资源管理 | 解析超时/内存限制、进程树清理、陈旧任务/锁识别、故障注入 | 批量解析和长任务中断后仍有人工处理 |
| 特征层 | 截止时间窗口、标签生成、训练集预处理、固定动作空间 | 当前输出是整场快照 |
| 模型层 | 基线、深度学习网络、损失、训练、独立评估、置信度与适用域 | 训练协议已预留，效果完全待验证 |
| 产品层 | 网页上传、任务进度、地图轨迹、队友/敌方可见上下文 | 当前以本地 CLI 和静态报告使用 |

`doctor` 目前检查回放数据包和数据集；它不巡检模型、运行、报告、缓存或原始 demo，也不会自动修复损坏。更多具体边界见[风险复核](project-review.md)。
